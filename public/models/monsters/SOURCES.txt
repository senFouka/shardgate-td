Shardgate TD - creep models (public/models/monsters). Prepared 2026-10-07.
All files are glTF 2.0 binary (.glb), Y-up, ground creeps stand on y=0 (flying ones hover above y=0 as authored).
Each GLB is self-contained (no external URIs). No Draco / Meshopt. Geometry uses KHR_mesh_quantization
(core three.js GLTFLoader support, no decoder needed). Index of all models: catalog.json.

Processing (scripts in the dev scratchpad, not shipped)
=====================================================================
gltf-transform 4 + sharp: keep only the move / death / hit clips (CharacterArmature| prefix stripped,
Blob "HitRecieve" renamed to "HitReact"), resample keyframes, drop animation channels that only hold the rest pose,
Quaternius: colors baked to vertex colors (COLOR_0) with one shared PBR material (metal 0, rough 1), no texture,
1 draw call per model; KayKit: 1024px texture reduced to an embedded 256px palette PNG (5 KB), body parts merged per material.
Quantization: POSITION 14-bit, NORMAL 8-bit, WEIGHTS 8-bit (KHR_mesh_quantization).
Verified with three.js 0.186 GLTFLoader in Node: all files load, every animation track binds to a scene node,
animated bounds match the source files.
